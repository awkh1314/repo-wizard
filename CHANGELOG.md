## [0.1.1] - 2026-08-01

### Added

## [0.1.0] - 2026-08-01

### Added
- `init`: interactive scaffolding of a full open-source file set.
- `check`: audit an existing repo and score open-source readiness (0-100).
- Zero dependencies (pure Python standard library).
- Language-aware `.gitignore`, bilingual README, GitHub templates, CI workflow.
